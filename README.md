In a vast digital landscape, a lone data packet is on a critical mission—to deliver vital information from one router to another without being lost or corrupted. But the network is riddled with interferences that drain its energy and interceptors that threaten to erase it entirely. Can the packet navigate through the chaotic web of signals and reach its destination before time runs out?

Route404 is a casual mobile game where you have to control a packet of data in a network of routers. Obstacles may appear suddenly and you have to navigate the packet away from them, reaching the destination in time safely.

# Tools Used

The project is built in Unity 6 with C# scripts.

# How to Run

To run the project, you must install Unity engine. You also need the C# .NET support to execute the C# scripts.
